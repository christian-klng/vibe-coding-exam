## Worum geht es?
Ein **Repository** (kurz „Repo“) ist der Ordner deines Projekts – mit allen Dateien und ihrer kompletten Änderungsgeschichte. **GitHub** speichert dieses Repo online, damit du von überall daran arbeiten, es teilen und später veröffentlichen kannst.

## Warum ist das wichtig?
Fast alle weiteren Aufgaben prüfen wir direkt in deinem Repo. Außerdem ist es deine Versicherung: Geht beim Vibe Coding etwas kaputt, kannst du jederzeit zu einem funktionierenden Stand zurück.

## So gehst du vor
1. Lege ein kostenloses Konto auf [github.com](https://github.com) an.
2. Erstelle ein neues Repository und wähle **Public** (öffentlich), damit wir es lesen können.
3. Hake „Add a README file“ an – so entsteht direkt der erste Commit.
4. Kopiere die Adresse (z. B. `https://github.com/deinname/meine-app`) und trage sie hier in der App ein.

## Gut zu wissen
Öffentlich heißt: Jede Person kann deinen Code sehen. Deshalb gehören Passwörter und API-Keys niemals ins Repo – dazu später mehr.
