## What is this about?
A **repository** (“repo”) is your project folder – with all files and their complete change history. **GitHub** stores this repo online so you can work on it from anywhere, share it and publish it later.

## Why does it matter?
We check almost every following task directly in your repo. It is also your safety net: if something breaks while vibe coding, you can always go back to a working version.

## How to do it
1. Create a free account on [github.com](https://github.com).
2. Create a new repository and choose **Public** so we can read it.
3. Tick “Add a README file” – this creates your first commit right away.
4. Copy the address (e.g. `https://github.com/yourname/my-app`) and enter it here in the app.

## Good to know
Public means: anyone can see your code. That is why passwords and API keys never belong in the repo – more on that later.
