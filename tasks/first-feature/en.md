## What is this about?
Time to build! The goal is a feature that is **really finished** – not just “looks like it”. You define what “finished” means up front: the **definition of done**. For example: “You can add an appointment, it is saved and still there after reloading.”

## Why does it matter?
AI-generated code often looks finished quickly but only half works: data isn't saved, errors aren't handled. With a clear definition of done you can check yourself whether the AI did its job.

## How to do it
1. Pick the story from your plan.
2. Write 2–3 points under the story: how do you know it is done?
3. Let the AI implement it and **try it yourself** – point by point.
4. Mark the story as done in `docs/user-stories.md` (`- [x]` or ✅).
5. Optional: add the new feature to the README.

## Tip: How to ask Claude Code
> “Implement the plan in docs/plans/…. Afterwards check every point of the definition of done and tell me how I can test it myself in the browser.”
