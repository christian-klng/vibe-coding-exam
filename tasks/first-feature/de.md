## Worum geht es?
Jetzt wird gebaut! Ziel ist ein Feature, das **wirklich fertig** ist – nicht nur „sieht so aus“. Was „fertig“ bedeutet, legst du vorher fest: die **Definition of Done**. Zum Beispiel: „Man kann einen Termin eintragen, er wird gespeichert und ist nach dem Neuladen noch da.“

## Warum ist das wichtig?
KI-generierter Code sieht oft schnell fertig aus, funktioniert aber nur halb: Daten werden nicht gespeichert, Fehler nicht abgefangen. Mit einer klaren Definition of Done kannst du selbst prüfen, ob die KI ihre Arbeit erledigt hat.

## Tipp: So fragst du Claude Code
> „Setz den Plan in docs/plans/… um. Prüf danach jeden Punkt der Definition of Done und sag mir, wie ich ihn selbst im Browser testen kann.“
