## Worum geht es?
Die **README** ist die Visitenkarte deines Repos. GitHub zeigt sie automatisch auf der Startseite des Repos an. Sie ist in **Markdown** geschrieben – einem einfachen Textformat, in dem z. B. `# Titel` eine Überschrift wird.

## Warum ist das wichtig?
Wer dein Repo öffnet – Mitgründer:innen, Lehrende, Investor:innen oder du selbst in drei Monaten – soll in einer Minute verstehen, worum es geht und wie man die App startet. Auch Claude Code liest die README, um dein Projekt zu verstehen.

## So gehst du vor
1. Öffne (oder erstelle) `README.md` im Hauptordner deines Repos.
2. Beginne mit Name und einem Satz, was die App ist und für wen.
3. Liste die wichtigsten Funktionen auf.
4. Beschreibe Schritt für Schritt, wie man die App lokal startet.
5. Gliedere mit Überschriften (`##`).

## Tipp: So fragst du Claude Code
> „Schreib eine README für mein Projekt. Nutze docs/idee.md für die Beschreibung und schau im Code nach, wie man die App startet. Halte sie kurz und verständlich für Einsteiger.“
