## Worum geht es?
Eine **User Story** beschreibt eine Funktion aus Sicht der Person, die sie nutzt:

> Als **Studentin** möchte ich **meine Prüfungstermine eintragen**, damit **ich sehe, wie viel Zeit mir bleibt**.

Sie sagt *wer* etwas *warum* tun will – aber nicht *wie* es technisch gebaut wird.

## Warum ist das wichtig?
User Stories sind die perfekte Arbeitsgrundlage für die KI: Jede Story kann später ein eigener Prompt und ein eigenes Feature werden. Und du merkst früh, welche Funktionen wirklich wichtig sind.

## So gehst du vor
1. Lege `docs/user-stories.md` an.
2. Schreibe mindestens fünf Stories nach dem Muster „Als … möchte ich …, damit …“.
3. Optional: Sortiere sie nach Wichtigkeit (Muss / Soll / Kann).

## Tipp: So fragst du Claude Code
> „Lies docs/idee.md und schlag mir zehn User Stories vor. Ich wähle dann die fünf wichtigsten aus.“
