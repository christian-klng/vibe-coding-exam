## What is this about?
A **user story** describes a feature from the point of view of the person using it:

> As a **student** I want to **enter my exam dates** so that **I can see how much time I have left**.

It says *who* wants to do something and *why* – but not *how* it is built technically.

## Why does it matter?
User stories are the perfect input for the AI: each story can later become its own prompt and its own feature. And you notice early which features really matter.

## How to do it
1. Create `docs/user-stories.md`.
2. Write at least five stories following “As a … I want … so that …”.
3. Optional: sort them by importance (must / should / could).

## Tip: How to ask Claude Code
> “Read docs/idea.md and suggest ten user stories. I will then pick the five most important ones.”
